Page reveal

Every navigation reveals the next page through a soft-edged circle that grows from where you clicked. The old page zooms past and blurs underneath and is wiped out just inside the circle’s edge, while the new page zooms up into focus. The whole transition runs 800 ms.

Easing

Five curves

Each dot sits where the playhead puts the animation named under its curve.

Mask

Two gradients from one radius

r = --reveal × 2.5 × reach ÷ --zoom

reach is the distance from the start point to the farthest corner of the screen. --reveal is a registered <number>, so it can animate from 0 to 1 and the gradient follows it.

New page: solid inside 0.4r, then an S-shaped fade to nothing at r. At --reveal: 1 the solid centre is exactly reach across, so the page covers the screen as the animation ends.

Old page: hidden inside 0.4r, fully visible from 0.7r. It is gone wherever the new page is solid, so it never shows through gaps in the new page. In the shaded band, both pages are partly visible.

The zoom is cancelled out. Each mask is drawn in its own snapshot’s coordinates, so it zooms with its page. The zoom runs through a registered --zoom that sets scale, and the radius is divided by it. At 400 ms the old page is at 1.106× and the new at 0.976×, and both circles measure 740.8 px on screen.

Click

Pointer position

Keyboard

Centre of the link

Enter on a link fires a click with detail === 0 and no coordinates, so the centre of the link’s box is used.

Back / forward

Centre of the screen

There is no click. popstate clears any stored point, so the reveal starts from the middle.

Each snapshot is as large as its element (often far taller than the screen) and placed by its group’s transform. Once the transition is ready, onExit and onEnter subtract each group’s offset and write the point into that snapshot’s own coordinates. Both pages render main and a footer, so there are four rules. These came from a click on the Digital production card:

/* injected into <head>, removed when the transition ends */
          ::view-transition-old(_t_0_) { --reveal-x: 84px; --reveal-y: 1753px; --reveal-reach: 1481.6px; }
          ::view-transition-old(_t_0__1) { --reveal-x: 84px; --reveal-y: -499px; --reveal-reach: 1481.6px; }
          ::view-transition-new(_t_1_) { --reveal-x: 84px; --reveal-y: 215px; --reveal-reach: 1481.6px; }
          ::view-transition-new(_t_1__1) { --reveal-x: 84px; --reveal-y: -3642px; --reveal-reach: 1481.6px; }

The same point is the transform-origin for both pages, so the zoom also starts from it.

Under prefers-reduced-motion: reduce every view transition animation is removed and both masks are turned off, so pages swap instantly.

Notes filter

Rows keep the old fade

Filtering the notes list animates rows, not pages. Rows that leave or arrive use their own .filter class with the fade the pages used before, and rows that stay slide to their new place. The footer is lifted out as notes-footer so it slides with them.
