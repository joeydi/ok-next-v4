The faces are the `--font-*` variables and the letter spacing the `--tracking-*` variables in the `@theme` block of `src/app/globals.css`. The sizes are the `--text-fl-*` variables in `src/app/fluid.css`, which `scripts/fluid.mjs` generates: edit the script and rerun it, never the CSS. Every value on this page is read from those files. Use them as classes (`display`, `mono-label`, `mono-text`, `text-fl-24`, `tracking-display-24`) rather than px or em values inline.

## Typefaces

Hanken Grotesk and IBM Plex Mono come through `next/font` in `src/app/layout.tsx`, so they're self-hosted and preloaded. Gelica comes from an Adobe Fonts kit, and each live domain has to be added to the kit.

## Scale

Each size is a straight line through its smallest px at a 320 window and its design px at 1440, carried on to 1920 and clamped at both ends. The comps come out exactly as specced, and phones and wide screens scale in proportion. Resize the window to see where it falls.

## Tracking

Gelica is tightened as it gets bigger, on a scale `scripts/fluid.mjs` generates like its line heights: one `tracking-display-*` token per size, from −0.02em at 30 (and below) to −0.035em at 168, on the same log curve. Use the one matching the size, headings and running text alike (`text-fl-96 tracking-display-96`). The mono caps are opened up instead. `tracking-display` remains only for the social cards' titles, whose size isn't on the scale. Each token is set over the same text without it.

## Styles in use

Line heights are always numbers. Anything that sets none takes `--leading-body` (1.3, Hanken Grotesk's own `normal`), intro paragraphs use `--leading-intro` (1.5), Gelica takes its line height from two scales that `scripts/fluid.mjs` generates, one token per size: headings use `leading-heading-*` (1.1 at 30 down to 0.85 at 168) and running text such as the note lead, list items and quotes uses `leading-display-text-*` (1.3 at 24 down to 0.85), so use the one matching the size (`text-fl-48 leading-heading-48`). body copy (cards, lists, descriptions and note articles) uses `--leading-copy` (1.6, as `leading-copy`), the mono utilities set `--leading-mono` (1.6) and code blocks `--leading-code` (1.5). Avoid Tailwind's `leading-normal`: it's 1.5, not the font's `normal`, so use `leading-intro` instead.
