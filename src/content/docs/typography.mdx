The faces are the `--font-*` variables and the letter spacing the `--tracking-*` variables in the `@theme` block of `src/app/globals.css`. The sizes are the `--text-fl-*` variables in `src/app/fluid.css`, which `scripts/fluid.mjs` generates: edit the script and rerun it, never the CSS. Every value on this page is read from those files. Use them as classes (`display`, `mono-label`, `mono-text`, `text-fl-24`, `tracking-heading`) rather than px or em values inline.

## Typefaces

Hanken Grotesk and IBM Plex Mono come through `next/font` in `src/app/layout.tsx`, so they're self-hosted and preloaded. Gelica comes from an Adobe Fonts kit, and each live domain has to be added to the kit.

  </Typeface>
  <Typeface
    font="mono"
    name="IBM Plex Mono"
    source="next/font"
    weights={[500]}
    use="mono-label for caps; mono-text for numbers and meta. Both 14 / 1.6."
  >
    Labels, the nav, numbers and dates. Only 500 is loaded, so mono renders at 500 whatever weight it asks for. It has no “→”, which falls through to the system monospace.
  </Typeface>

## Scale

Each size is a straight line through its smallest px at a 320 window and its design px at 1440, carried on to 1920 and clamped at both ends. The comps come out exactly as specced, and phones and wide screens scale in proportion. Resize the window to see where it falls.

## Styles in use

Line heights are always numbers. Anything that sets none takes `--leading-body` (1.3, Hanken Grotesk's own `normal`), the mono utilities set `--leading-mono` (1.6) and code blocks `--leading-code` (1.5). Note that Tailwind's `leading-normal` is 1.5, not the font's `normal`.

Every combination of face, size, weight, leading and tracking set in `src/app`, `src/components` and `globals.css`, found by scanning the source, so this list follows the code. Tracking written inline instead of from a token is marked in pink: a value that turns up in more than one place is a candidate for a new `--tracking-*` token.
