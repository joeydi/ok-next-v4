The tokens are the `--color-*` variables in the `@theme` block of `src/app/globals.css`, and every value on this page is read from there. Use them as Tailwind classes (`bg-paper`, `text-muted`) or as `var(--color-…)`, never as a hex.

Their hues come from the `--hue-*` tokens above them. The pinks are `hsl(var(--hue-accent) S% L%)`. The papers, rules and inks run from `--hue-neutral-cool` at black to `--hue-neutral-warm` at white: `--neutral-hue-span` is the turn between the two, the shorter way round the wheel as CSS interpolates hues, and each neutral's hue is the cool one plus that span times its lightness, written as `hsl(calc(var(--hue-neutral-cool) + var(--neutral-hue-span) * 0.925) S% 92.5%)`. Change a hue and its family follows, keeping its saturation and lightness. A new neutral needs only a lightness: its saturation is the rule below, and its hue the ramp.

The terminal colours, for the marks the site check draws on ink, are Moonlight's green and yellow from the code blocks (see Syntax below), each on a hue of its own, `--hue-term-green` and `--hue-term-yellow`.

## Syntax

Code blocks in notes are highlighted in a palette of their own, based on atomiks' Moonlight theme. `src/lib/code-theme.json` maps every kind of token to a `--code-*` variable, and the values are set in `src/app/globals.css`, in the `.note-body` code rules. Moonlight's text colours, comments and reds are replaced by the site's neutrals and pink, so a block sits on ink like the rest of the page. Its other hues are kept as hex values. Only its green and yellow are used elsewhere, by the site check, so those two are `--color-term-*` tokens the blocks read. Contrast is measured against `--code-background`, the only ground they're drawn on, and anything under 4.5:1 is marked in pink.

```js showLineNumbers {3}
// Scrub a line up out of the water as it scrolls by.
export function surface(line, { depth = 40, ease = "expo.out" } = {}) {
  const text = line.querySelector("span");
  if (!text) return null;
  return gsap.to(text, { y: 0, filter: `blur(${depth}px)`, ease, scrollTrigger: { trigger: line, scrub: true } });
}
```
