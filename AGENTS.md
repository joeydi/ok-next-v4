# okaypl.us

Next.js 16 (App Router) + Tailwind v4 + MDX, deployed on Vercel. Every route is statically generated.
The original design handoff lives in `design_handoff_okayplus_site/` — treat it as the visual reference (1440px comps in `screenshots/`).

- **Tokens** — colours, fonts and utilities (`px-page`, `grid-12`, `mono-label`, `display`, `stripes`, `nudge`) and the shared hover treatment (`hover-card`, `hover-title`, `hover-lift`) are in `src/app/globals.css`.
- **Fluid scale** — `src/app/fluid.css` is generated by `node scripts/fluid.mjs`; edit the script, not the CSS. Tokens (`text-fl-*`, `*-fl-*` spacing, `px-page`) scale linearly 320→1920px and hit the exact design px at 1440. Use them instead of fixed px.
- **Page width** — wrap page-level blocks in `<Container>` (`src/components/Container.tsx`, takes `as`): gutter padding, capped at `--container-page` (1920px, set in `fluid.mjs`) and centred. Full-bleed backgrounds go on a parent. For sizes taken from the comp as a share of the viewport, use `calc(N*var(--pvw))`, not `Nvw`, so they stop growing at the cap too.
- **Copy** — Home and service page copy is data: `src/data/home.ts`, `src/data/services.ts` (`*word*` in an H1 renders pink). Site constants (email, booking URL) in `src/data/site.ts`.
- **Illustrations** — `src/components/illustrations/`: pure CSS 3D, server-rendered, on a fixed 620×660 canvas that scales to its container. Keyframes in `illustrations.css`; the puzzle cube generates its own. `prefers-reduced-motion` stops all of them.
- **Media** — images/videos live in R2; `src/data/media.json` (committed, written by `scripts/media.mjs` and the dev-only `/admin/media`) describes them. Pass `getMedia(key)` from `src/lib/media.ts` (server-only) to `Placeholder`/`Figure`; unknown keys fail the build. Client-safe URL helpers are in `src/lib/media-url.ts`. `*.dev.tsx` routes exist only under `next dev`. Setup is in the README.
- **Notes / case studies** — `src/content/notes/*.mdx`. Frontmatter is parsed + validated in `src/lib/notes.ts`. MDX components (`Lead`, `Figure`, `PullQuote`, `TocAnchor`) are registered in `src/mdx-components.tsx`; article grid layout lives in the `.note-body` rules in `globals.css`.
- **Verify visually** against the design screenshots at 1440 plus 320/390/768/1024/1920 before calling layout work done.
